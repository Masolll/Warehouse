# 📦 Warehouse Web API
ASP.NET Core Web API для учета рулонов на складе и получения агрегированной статистики за выбранный период.
Проект реализован в рамках задания по стажёрской программе IT HUB «Северстали» и покрывает все обязательные требования, а также часть дополнительных.

## 🛠 Технологический стек
- .NET 8 / ASP.NET Core Web API
- Entity Framework Core
- PostgreSQL

## ⭐ Реализованный функционал
- Добавление рулона на склад (длина и вес обязательны)
- Удаление рулона по id
- Получение списка рулонов. Поддерживается фильтрация по нескольким диапазонам сразу:
  - id
  - длина
  - вес
  - дата добавления
  - дата удаления
- Получение статистики за указанный период (конец периода невключительно):
  - количество добавленных рулонов
  - количество удалённых рулонов
  - средняя длина и вес
  - минимальная и максимальная длина и вес
  - суммарный вес рулонов
  - минимальный и максимальный срок хранения рулона
- Дополнительная статистика за указанный период:
  - день с минимальным и максимальным количеством рулонов на складе
  - день с минимальным и максимальным суммарным весом рулонов
## 🗄 Хранение данных
- Данные хранятся в PostgreSQL
- Используется Entity Framework Core
- Строка подключения к БД задается через appsettings.json
## ⚠ Обработка ошибок
Для обработки исключений был написан middleware UseGlobalExceptionHandler. Middleware перехватывает необработанные исключения и возвращает корректные HTTP-ответы, в том числе для следующих сценариев:
- недоступность базы данных
- попытка работы с несуществующим рулоном
- другие непредвиденные ошибки сервера
